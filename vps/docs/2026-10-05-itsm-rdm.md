## Configuração operacional

- `HOMOL=true` mantém o ambiente sintético já existente e seu login de homologação. Não representa produção institucional.
- `RDM_FLUXO_HABILITADO=true` e `RDM_UPLOAD_HABILITADO=true`.
- Quatro secrets do Komodo são referenciados no environment da Stack: banco, NextAuth, `ITSM_HOM_RDM_ENTREGAS_CHAVE` e `ITSM_HOM_RDM_JOBS_SECRET`. Os dois novos valores foram gerados uma única vez e preservados no Komodo. Nunca rotacionar a chave de cifragem sem migração dos dados cifrados.
- Volume externo existente `itsm-hom_anexos`, `ANEXOS_DIR=/dados/anexos`.
- ClamAV no host, assinaturas atualizadas, socket Unix `/run/clamav/clamd.ctl`, `0660`, grupo `clamav` (GID 114 neste host), montagem somente leitura. Não expor porta TCP do scanner.
- O Compose inicia `node server.js`. Migrações são explícitas e controladas; não usar o CMD legado da imagem que executa `db push --accept-data-loss`.
- Timer `itsm-rdm-job.timer` ativo a cada cinco minutos; o driver usa `docker exec` no container `itsm-hom-itsm-hom-1`, lê o segredo do ambiente do próprio container, exige resposta JSON 2xx e falha em redirecionamento, timeout ou erro HTTP. O nome depende do nome atual da Stack/Compose; atualizar o driver ao renomear a Stack.
- Origem segue protegida por Cloudflare, firewall e AOP no Traefik. Router aceita `itsm.lglabs.tech` e o hostname anterior.

Instalação das units e override (após instalar ClamAV e atualizar assinaturas):

```sh
sudo install -m 0644 vps/etc/systemd/system/itsm-rdm-job.service /etc/systemd/system/
sudo install -m 0644 vps/etc/systemd/system/itsm-rdm-job.timer /etc/systemd/system/
sudo install -d /etc/systemd/system/clamav-daemon.socket.d
sudo install -m 0644 vps/etc/systemd/system/clamav-daemon.socket.d/zz-itsm.conf /etc/systemd/system/clamav-daemon.socket.d/
sudo systemctl daemon-reload
sudo systemctl enable --now itsm-rdm-job.timer
sudo systemctl start itsm-rdm-job.service
sudo journalctl -u itsm-rdm-job.service -n 10 --no-pager
```

O driver permanece em `/home/mateus/infra/dotfiles/vps/bin/itsm-rdm-job.py`. Aplicar o override do scanner requer recriar o socket em janela controlada; verificar modo e grupo antes de liberar upload.
